⚙️ Pengaturan Guru & Panduan Koneksi Spreadsheet

📋 Langkah menghubungkan jawaban ke Google Spreadsheet (5 langkah)
  1. Buat Google Spreadsheet baru di Google Drive (ketik sheets.new di browser). Beri nama, misalnya Nilai Latihan ASAS Kimia X.
  2. Di spreadsheet itu, buka menu Ekstensi → Apps Script, hapus kode bawaan, lalu tempel seluruh kode dari kotak di bawah (tombol Salin kode). Simpan (Ctrl+S).
  3. Klik Terapkan (Deploy) → Deployment baru → Aplikasi web. Isi: Jalankan sebagai: Saya dan Siapa yang memiliki akses: Siapa saja (Anyone) → Terapkan → izinkan akses akun Google Anda. Salin URL Web App (berakhiran /exec).
  4. Tempel URL itu pada kolom di atas, klik Simpan pengaturan, lalu Uji koneksi. Bila muncul “API aktif”, koneksi berhasil.
  5. Bagikan file HTML ini ke siswa (WhatsApp/Google Classroom). Setiap siswa yang menekan Kumpulkan otomatis menambah satu baris di sheet “Jawaban Latihan”.

Kolom “Skor Esai Otomatis” adalah skor awal berbasis kata kunci — koreksi akhir tetap di tangan guru melalui kolom “Nilai Final Guru”. Jika ingin dibuka online tanpa unduhan, file HTML dapat di-hosting statis gratis (mis. Netlify Drop / GitHub Pages).
